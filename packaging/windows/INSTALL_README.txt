LungSight 0.1.0-beta.2 · 参赛演示测试版本
QIONX · 联系邮箱：2934935729@qq.com

运行环境：Windows 10/11 64 位，建议内存 8 GB 以上，至少预留 4 GB 磁盘空间。
已包含 Python、Node.js、CPU 推理依赖及五折研究模型，不必另行安装运行环境或显卡驱动。
如果电脑缺少 Microsoft VC++ x64 运行库，安装器会征求同意后从微软官网下载，校验文件并打开微软安装向导；此步骤需要联网及管理员确认。已有兼容运行库时跳过。

安装后双击桌面 LungSight。启动器就绪后将在默认浏览器打开工作区。
关闭启动器窗口会停止本地服务；只关闭浏览器不会停止服务。
软件使用本机 18000/18001 端口，仅监听回环地址，不向局域网公开。

首次使用请自行注册账号。分发包不含开发者账号、API Key、CT 病例或问答记录。
CT 本地分类不需要 API Key。调用在线医学问答/解释模型需要在设置中心配置自己的 API Key，并可能产生服务商费用。
参赛演示步骤见安装目录 DEMO_GUIDE.md。新增影像缩放与叠加、人工标记、病例工作区和可恢复的后台分析任务。
设置页显示本地模型实际加载状态；缺少权重时仍可进入账号、历史记录和问答。
刷新页面可恢复任务进度；软件重启后请在后台任务中点击继续。未保存标记或复核内容在切换和关闭前会提醒。
失败或取消的任务保留规范化输入用于重试；可在任务面板主动释放缓存，已保存结果仍保留。
在线模型调用会发送脱敏后的问题与检索上下文；请勿输入身份信息。没有配置 Key 不会自动使用开发者的账号。

用户记录：%LOCALAPPDATA%\LungSight\data
运行日志：%LOCALAPPDATA%\LungSight\logs
升级和卸载默认保留上述用户记录。需要迁移时，先关闭软件，再完整备份 data 文件夹（包含本机凭据加密所需文件），不要公开该文件夹。

资料库内置原创整理摘要、外部资源索引及模型说明，不包含未经许可的整篇第三方论文或训练图片。
当前为研究性原型。五折模型结果不等同于癌症概率或病理确诊，不能承诺识别任意临床 CT，不用于独立临床诊断或治疗决策。

本测试安装包暂未配置开发者代码签名。请只从项目负责人提供的渠道下载并核对 SHA256，不应关闭系统安全防护。
如提示端口冲突或启动失败，请查看启动器的日志；不要删除已有数据来排错。
