# LungSight 工作区补充说明

本次实现位于本地分支 `codex/workbench-improvements`，基于公开仓库的 `80932e2`。范围为影像查看器、病例工作区联动、后台任务进度与失败恢复。未修改官网内容、模型清单、模型权重或临床适用性状态。

## 已实现

### 影像查看器

- 分析页和病例页共用查看器，支持 1–6 倍缩放、拖动平移、重置、亮度与对比度调整。
- 支持前后切片、滑块和左右方向键；显示的是已经分析并保存的切片。
- Grad-CAM 可叠加并调整透明度。修正非正方形影像的映射：先移除模型输入的填充边缘，再投影回原图。
- 人工点标记按切片保存，可填写备注、移除标记，并将备注预填到该切片的问答中。预填后仍需用户发送。
- 标记使用相对原图的坐标，缩放和平移不改变其位置。并发修改使用版本检查，旧窗口不能覆盖较新的记录。
- 标记写入审计记录，并进入单张报告和整组报告；备注中的 HTML 字符会转义。

### 病例工作区

- 在同一页面切换所属序列的切片，查看模型输出、质量提示、人工标记和复核记录。
- 在页面内填写复核意见，成功后显示锁定状态；保存失败保留输入。复核仍由用户主动提交，不会自动生成。
- 提供“解释复核重点”“解释质量提示”入口，使用既有的证据问答服务。
- 引用摘录可展开阅读；本次问答是否附入报告由用户选择。
- 整组报告收集各切片明确选择附入的问答，包含非代表切片的人工标记。

### 后台任务

- 单张、批量图片和 DICOM 派生切片统一通过 `/api/analysis-jobs` 提交。
- 提交时先校验、规范化图片或转换 DICOM；进入队列后显示读取、质控、推理、注意力图和保存阶段。
- 页面刷新后可以重新连接正在进行的任务。后端重启后将未完成任务标记为中断，由用户点击继续。
- 可以取消剩余处理；取消在计算阶段之间生效，不会强行中断正在执行的模型运算。
- 重试只处理未完成项，已成功的切片及任务编号保留。对于“结果已落库、队列还未确认”时发生的中断，也会复用已有结果。
- 部分完成的序列可以归档；继续处理后生成新的汇总记录，保留此前的部分结果记录。
- 队列和标记按账号隔离。永久删除切片时也清理其标记及队列结果副本；仍在处理的任务需要先取消或完成。

## 兼容与修复

- 保留原来的同步分析接口；耗时推理移出异步请求线程，五折推理和 Grad-CAM 使用同一模型锁。
- 新表在本地数据库中按需建立，不重建已有账号、病例或复核记录。
- 新环境从随仓库提供的模型说明建立基础资料索引，启动不再依赖开发者私有 PDF 或压缩包。
- Windows 打包清单加入新模块，并修正说明文档的源目录。
- 修复评测模块 SQLite 连接未及时关闭造成的 Windows 文件占用。

## 使用与边界

先准备与 `backend/model_manifest.json` 哈希匹配的五个模型权重，放入 `backend/weights/`。当前 checkout 不包含权重，因此本次没有验证真实五折推理速度、分类效果或安装包运行，也没有调用真实外部大模型服务。

在仓库根目录运行后端，保持单进程：

```powershell
& .\backend\.venv\Scripts\python.exe -m uvicorn app:app --app-dir backend --host 127.0.0.1 --port 8001
```

另开终端运行已验证的前端生产构建：

```powershell
pnpm build
pnpm start --hostname 127.0.0.1 --port 3000
```

然后访问 `http://127.0.0.1:3000/analysis`。当前 Windows 环境的开发模式 Cloudflare worker 曾启动失败，本次浏览器验收使用了生产构建。

查看器不是完整 DICOM 阅片器：亮度、对比度不是 HU 窗宽窗位，不包含 MPR、三维重建、自动病灶分割或毫米测量。人工标记是研究备注。未保存的备注请在切换切片前保存。

队列成功后释放对应的输入缓存；失败或取消的规范化图片保留在本机数据库中供重试，目前没有自动过期清理。DICOM 原文件与身份字段值不写入队列；像素隐私仍需要人工核对。

本次工程验证不改变研究模型、弱标签、病例级拒判以及临床验证的既有边界。
