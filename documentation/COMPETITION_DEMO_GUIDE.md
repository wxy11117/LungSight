# LungSight 参赛演示流程

本版本为研究原型。演示使用仓库自带的公开示例；示例名称与模型输出不构成临床验证结果。建议先在演示电脑完整走一遍流程。

## 准备

1. 安装并启动 LungSight，保持启动器打开。在浏览器注册自己的本地账号。
2. 打开设置，确认本地影像模型显示 5 / 5。影像分析在本机运行。
3. 如需展示在线问答，在设置中选择 DeepSeek 和 `deepseek-flash`，输入自己的 API Key，保存并验证连接。密钥不要放入录屏、聊天或参赛附件。
4. 离线时先展示影像流程；在线问答需要网络与服务商账户可用。安装包内不附带任何开发者密钥、账号、病例或聊天记录。

## 建议的三至五分钟演示

1. **影像分析**：选择一个内置示例，运行本地五折分析。说明后台队列显示质控、推理、注意力图、保存等阶段；不要将内部分类概率称为患癌概率。
2. **交互查看**：放大和平移影像，启用 Grad-CAM 叠加并调整透明度。注意力图解释模型关注区域，不等同于病灶分割。
3. **人工标记**：在影像上添加一条“演示备注：核对该区域显示效果”，保存后进入病例工作区。标记使用相对原图坐标，随缩放保持位置。
4. **证据问答**：点击“解释复核重点”。展示回答中的本地引用与限制说明；说明发送的是问题和结构化上下文，CT 像素不上传至问答服务商。需要将本次回答写入报告时，先勾选对应选项。
5. **人工复核与报告**：若演示复核保存，仅在明确的演示病例上选择“无法判断”，备注“演示操作，不是专业复核结论”。展示保存锁定、审计记录和报告下载。
6. **批量任务**（可选）：导入多张公开示例，展示切片浏览、取消剩余处理与继续；成功切片不会重复分析。病例级结论仍保持拒判。

## DICOM 与异常演示

- DICOM 只使用已获授权且完成相应隐私核对的数据，或明确的合成测试文件。导入前需要确认数据授权与像素隐私要求；系统不保存原始 DICOM 和身份字段值。
- 重启后在任务面板点击“继续 / 重试未完成项”。释放未完成项输入缓存后，需要重新选择文件，已保存结果可继续查看。
- 未保存的人工标记或复核内容会触发切换提醒。关闭页面、浏览器后无法恢复未保存输入。
- 若模型不可用，设置页会显示修复提示；不需要删除已有账号与病例来排错。

## 展示重点

展示一条可操作、可追溯的工作流程：影像输入 → 本地分析 → 可视化与人工备注 → 引用可核对的解释 → 人工复核 → 报告。工程联调成功不代表临床有效性、患者独立性或外部数据验证已经完成。
