# 历史问答操作

- 在Agent的历史问答库中右键单条记录，或聚焦条目后按Shift+F10，打开置顶、分享、复制、删除菜单。
- 置顶显示星号、排序靠前，重复置顶不会改变时间；取消置顶恢复问答时间顺序。状态保存在当前账号的本地后端数据库，刷新或重新登录仍保留。
- 分享打开所选对话的文本预览，可以复制或下载UTF-8文本。当前为本地工作区，不创建公开链接，不自动发送给第三方。
- 复制针对右键选中的对话，不是正在查看的其他对话。包含完整已保存问答、引用、风险、不确定性与免责声明，不包含API配置或账号资料字段。剪贴板受限时提供手动复制预览。
- 导出时重新执行常见个人信息脱敏，省略来源路径和内部元数据字段。自动脱敏无法保证覆盖所有敏感信息，分享前仍须人工复核。
- 回答生成中暂不允许历史操作，避免导出未完整保存的回答。
- 删除前展示所选标题并二次确认，默认聚焦取消。成功后移除历史条目，仅当删掉当前对话时清空聊天区，失败时保留记录并显示错误。采用软删除，原始消息、引用、用量和审计保留；不删除关联CT或已导出文件，目前没有界面恢复入口。

## 本地接口

- `PUT /api/agent/conversations/{id}/pin`：`{"pinned": true/false}`，返回会话ID及`pinned_at`。
- `POST /api/agent/conversations/{id}/export`：`{"purpose":"copy"/"share"}`，返回标题、文本和下载文件名。响应设置`Cache-Control: no-store`。
- `DELETE /api/agent/conversations/{id}`：软删除并取消置顶，返回204。同一账号重复删除仍返回204，不重复写入审计。列表、详情、分享、置顶和后续问答均不可再访问已删除记录。
- 三个操作接口均要求登录、所有权检查及来源校验，不接受客户端传入用户ID。不存在或归属其他账号返回404，非活动会话除本人重复删除外也返回404。
- 置顶/取消置顶及导出文本准备操作写入审计，导出准备不代表实际发送或分享成功。
- 迁移仅新增可空`agent_conversations.pinned_at`，不删除原有记录。运行`backend/backup_database.py`可在本地数据目录创建一致性备份。
