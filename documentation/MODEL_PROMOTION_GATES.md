# 模型晋级门控

医生身份认证不属于本轮修改范围。模型从本地研究预览晋级前，其余缺口按以下顺序关闭：

1. 建立患者/检查/序列级数据清单，保证同一患者不跨训练、验证和测试集合。
2. 将“正常”改为有明确纳入排除标准的对照定义；筛查阴性不能自动等同于正常。
3. 建立目标病灶 ROI 或可靠的病灶定位流程，停止对无病灶定位的等距切片作组织学推断。
4. 用与临床服务相同的 DICOM 解码、窗宽窗位、重采样和切片选择流程训练并验证。
5. 增加四类以外病例和图像域外检测，允许系统拒判，不能强迫任意输入落入四类。
6. 在锁定阈值后进行独立多中心外部测试，报告患者级混淆矩阵、敏感度、特异度、校准、覆盖率与置信区间。
7. 由合格专业人员完成标签定义、错例审查和临床用途签署；再创建新模型版本，禁止直接修改当前研究模型的安全字段。

当前机器可自动检查的硬门控已经写入 `backend/model_manifest.json`，并由后端启动时校验。任何缺失安全字段、允许临床使用或关闭病例级强制拒判的清单都会拒绝加载。
