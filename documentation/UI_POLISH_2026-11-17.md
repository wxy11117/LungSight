# 工作台界面与交互更新

版本：0.1.0-beta.3。范围是本地软件的分析、病例、病例库与设置页面。

本地安装文件：`releases/0.1.0-beta.3/LungSight-Setup-0.1.0-beta.3-win-x64.exe`，668,272,833 字节。SHA-256：`FBF6A45457C1916C4749569A3D222D2F179BAC5BAE54751B58DB75BB774DA7A1`。发布前已同步软件首页与官网说明并重新封包；保留 beta.2 与上一份本地 beta.3 构建。公开版本见 [beta.3 Release](https://github.com/wxy11117/LungSight/releases/tag/v0.1.0-beta.3)。

## 界面变化

- 统一卡片、间距、按钮、描边图标与焦点样式，修复分析页标题被旧状态卡片样式覆盖的问题。
- 将分析页拆分为输入、影像查看、结果三部分，新增三步流程提示、本地模型就绪状态与示例缩略图。
- 增大正文、结果概率和表单字号；小屏下自动排列为单列。设置导航使用独立横向滚动，避免撑宽整页。
- 工作区顶栏可直接切换亮色、夜间与护眼外观，保留现有外观偏好和配色机制。
- 医学影像画布保持中性暗色；显示调节仍不改变推理输入。

## 交互变化

- 文件拖入高亮，检查图片扩展名、文件数量、单文件大小和 DICOM 总量；普通图片与 DICOM 混合拖入会提示分开处理。
- 查看器增加缩放百分比、双击缩放、Ctrl/Command 加滚轮缩放、可展开的显示调节和全屏入口。
- 原生全屏不可用时自动使用窗口内大图，限制背景滚动、约束键盘焦点，并支持 Esc 退出。
- 增加加载、保存成功、模型刷新和任务进度反馈；尊重系统减少动态效果的偏好。
- 使用页内确认框保护人工标记、复核草稿和未保存的模型服务配置，支持取消继续编辑和明确放弃后切换。
- 模型服务保存或测试期间锁定表单，避免重复操作；未保存修改时提示先保存再测试连接。
- 保留原有研究排序、病例级结论阻断和人工复核边界。
